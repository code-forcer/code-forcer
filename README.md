## How to evaluate my work (for engineers & hiring managers)
1. Code quality: read module boundaries, naming, and documentation.
2. Tests & CI: run unit/integration tests. Examples:
   - Go: `go test ./...`
   - Node: `npm ci && npm test` or `yarn && yarn test`
   - Flutter: `flutter test`
3. Local dev & reproducible builds: many repos include Docker/compose or README run instructions. Typical flow:
   - git clone <repo>
   - cd <repo>
   - follow repo README (docker build / docker-compose up / npm run dev)
4. Performance & telemetry: look for simple benchmarks, logs, or observability hooks.
5. Security: check auth flows, secret handling, and payment integration patterns.

If you want, I can add per‑repository "How to run / Test" snippets (recommended for faster hiring reviews).
